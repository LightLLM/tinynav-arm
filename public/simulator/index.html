This view is kinematic: it computes where the arm goes, with no gravity, inertia or collisions. The robot is loaded from a URDF file (arm6.urdf). The same file runs with real physics in MuJoCo through the project's Python package.

Built with three.js (MIT) and urdf-loader (Apache-2.0).
